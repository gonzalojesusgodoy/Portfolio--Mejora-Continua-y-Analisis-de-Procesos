### 🐞 Resumen de defectos encontrados

| **Nombre** | **Tipo de defecto** | **Criticidad** | **Observaciones** |
|---|---|---|---|
| Registrarse con Datos Inválidos | Componente | Alta | El sistema permite registros con datos inválidos. |
| Navegar efectivamente entre solapas | Visual | Media | No permite navegar correctamente, afecta la usabilidad y la experiencia del usuario. |
| Búsqueda de vuelos | Componente | Alta | El sistema no muestra opciones de viajes, en ninguno de los datos que ofrece. |
| Selección de hoteles | Componente | Alta | No permite buscar ni reservar hoteles. |
| Reserva de hoteles con "fechas inválidas" | Componente | Alta | No permite buscar ni reservar hoteles. |
| Volver al inicio con el icono | Visual | Baja | Problema con el icono para salir de una solapa no deseada. |
