## 🐞 Reporte de Bugs

### BUG – 01

| Campo | Información |
|---|---|
| **ID** | BUG – 01 |
| **Título** | Navegación confusa y uso ineficiente del espacio en la interfaz de usuario |
| **Criticidad** | Media |
| **Ambiente** | Interfaz de usuario (UI) |
| **Tipo de defecto** | Visual |
| **Sistema operativo** | Windows |
| **Urgencia** | Media |
| **Descripción** | La página contiene dos barras de navegación (una superior y otra lateral), lo cual puede causar confusión en el usuario. Además, hay un espacio considerable sin utilizar en la página que podría ser aprovechado para mejorar la disposición y la presentación del contenido. |
| **Precondiciones** | Tener conexión a Internet. |
| **Pasos** | 1. Ingresar al link.<br>2. Registrarse.<br>3. Iniciar sesión.<br>4. Entrar a la pantalla de inicio. |
| **Resultado esperado** | La página debe contar con una navegación clara y coherente que facilite la experiencia del usuario. |
| **Resultado actual** | La página presenta dos barras de navegación (una superior y otra lateral), lo cual puede confundir a los usuarios al navegar por el sitio. Además, hay un espacio considerable sin utilizar en la página, lo que resulta en una disposición del contenido que no es óptima. Esto puede llevar a una experiencia de usuario menos intuitiva y a una presentación visualmente desequilibrada del contenido. |
| **Evidencia** | [Ver evidencia](https://drive.google.com/drive/folders/1QriacysUI0stkw50PctWn80Pp1QJtI-x?usp=sharing) |
