# 🧪 Registro de Experimentos y Validación

> 🎯 Objetivo: establecer cómo comprobar las hipótesis de mejora, bajo qué condiciones realizar las pruebas y qué evidencia se necesita para tomar una decisión.

## 🎯 1. Propósito

Este documento define el procedimiento para diseñar, ejecutar y evaluar pruebas destinadas a comprobar hipótesis de mejora.

A diferencia del registro de problemas, que identifica oportunidades, este documento se centra en **cómo validar una propuesta y determinar si sus resultados justifican mantenerla, modificarla o descartarla**.

Cada experimento deberá tener un objetivo definido, condiciones de prueba claras, indicadores relevantes y criterios de evaluación establecidos antes de analizar los resultados.

## 🔬 2. Diseño del experimento

Antes de realizar una prueba, se deberán definir los siguientes elementos:

- **Problema de origen:** situación que motiva el experimento.
- **Hipótesis:** resultado que se espera obtener y por qué.
- **Variable modificada:** factor que se cambiará durante la prueba.
- **Condiciones de referencia:** condiciones en las que funciona el proceso actual.
- **Indicadores:** variables que permitirán evaluar el resultado.
- **Condiciones de control:** aspectos que deben mantenerse constantes para que la comparación sea válida.
- **Riesgos y restricciones:** condiciones de seguridad, calidad, autorización y recursos.
- **Criterio de aceptación:** qué resultado se considerará suficiente para apoyar la propuesta.

Siempre que sea posible, se modificará un factor principal por prueba para facilitar la interpretación de los resultados.

## 🧪 3. Protocolo de prueba

Cada experimento deberá seguir una secuencia ordenada:

1. 📋 **Preparar:** definir el objetivo, los recursos y las condiciones de prueba.
2. 📊 **Establecer la referencia:** documentar la situación actual con la información disponible.
3. ⚙️ **Aplicar el cambio:** realizar la modificación autorizada.
4. 👀 **Observar:** registrar lo que sucede durante la prueba.
5. 📈 **Recopilar datos:** registrar los indicadores definidos.
6. 🔎 **Comparar:** analizar las diferencias respecto de la referencia.
7. ✅ **Concluir:** determinar qué se puede afirmar a partir de la evidencia.
8. 🔄 **Decidir:** mantener, modificar, descartar o repetir el experimento.

Si no se puede realizar una prueba, se documentará como propuesta pendiente, sin presentar resultados hipotéticos como si fueran reales.

## 📋 4. Ficha de experimento

Cada prueba se documentará mediante la siguiente ficha:

| Campo | Información requerida |
|---|---|
| ID del experimento | Identificador único |
| Hipótesis asociada | Referencia al registro de problemas |
| Objetivo | Qué se busca comprobar |
| Variable modificada | Qué cambia respecto del proceso actual |
| Condiciones de prueba | Recursos, entorno y restricciones |
| Indicadores | Qué se observará o medirá |
| Criterios de aceptación | Qué resultados apoyarían la propuesta |
| Riesgos y controles | Qué podría salir mal y cómo prevenirlo |
| Resultados | Datos y observaciones reales |
| Conclusión | Qué permite afirmar la evidencia |
| Decisión | Mantener, modificar, descartar o repetir |
| Estado | Propuesto, autorizado, ejecutado o evaluado |

## 🏭 5. Experimento 001 — Preparación previa de piezas

**🔗 Problema relacionado:** Preparación de piezas durante el montaje de módulos.

**🎯 Objetivo:** Evaluar si organizar y preparar previamente las piezas puede reducir las interrupciones durante el montaje sin generar problemas de calidad, abastecimiento o espacio.

**💡 Hipótesis:** Si los componentes están preparados y organizados antes de necesitarlos, podrían reducirse las interrupciones del montaje y mejorar la continuidad del trabajo.

**⚙️ Variable modificada:** Forma y momento de preparación de las piezas.

**📋 Condiciones de referencia:** Proceso actual, en el que las piezas se preparan durante el trabajo cuando no están disponibles previamente.

**🧪 Prueba propuesta:** Comparar el proceso actual con una preparación previa controlada, únicamente si la prueba está autorizada y cumple las condiciones de seguridad y calidad.

### 📊 Indicadores

- Tiempo dedicado a preparar las piezas.
- Tiempo de montaje.
- Interrupciones durante el proceso.
- Errores de identificación o selección.
- Espacio requerido para los componentes preparados.
- Efectos sobre el abastecimiento y las etapas relacionadas.

### ✅ Criterios de aceptación

Antes de ejecutar la prueba, deberán definirse los resultados mínimos esperados. La propuesta deberá evaluarse considerando la continuidad del montaje, la calidad, la seguridad y los posibles efectos sobre el proceso completo.

No bastará con reducir el tiempo de una tarea si el cambio genera problemas en otra etapa.

## 📈 6. Interpretación de resultados

Una vez ejecutado el experimento, los resultados deberán interpretarse de acuerdo con la evidencia disponible.

- 🟢 **Mantener:** los resultados cumplen los criterios establecidos y no aparecen efectos negativos relevantes.
- 🟡 **Modificar:** se observan beneficios parciales o dificultades que pueden corregirse.
- 🔴 **Descartar:** la propuesta no alcanza los objetivos o genera consecuencias negativas relevantes.
- 🔵 **Repetir:** la información es insuficiente, las condiciones cambiaron o se necesita comprobar la consistencia de los resultados.

Si la prueba no permite llegar a una conclusión clara, se deberá registrar esa limitación y evitar afirmar que la hipótesis está confirmada.

## 🛡️ 7. Seguridad, calidad y autorización

Ningún experimento deberá realizarse sin las autorizaciones correspondientes ni comprometer la seguridad de las personas, la calidad del producto o el funcionamiento de la línea.

Cuando una prueba no pueda ejecutarse, el diseño experimental podrá documentarse como una propuesta para una futura evaluación.

## 🗂️ 8. Historial de experimentos

Este registro se actualizará con cada prueba realizada e incluirá:

- Identificación y fecha del experimento.
- Versión de la propuesta evaluada.
- Condiciones en las que se realizó.
- Datos y observaciones obtenidos.
- Desviaciones o dificultades detectadas.
- Conclusiones y decisión final.

El historial permitirá mantener la trazabilidad de las pruebas y evitar que una misma hipótesis se evalúe repetidamente sin considerar los aprendizajes anteriores.

---

**🔑 Principio fundamental:** una propuesta no se considera validada por parecer razonable; debe evaluarse mediante criterios definidos y evidencia suficiente.
