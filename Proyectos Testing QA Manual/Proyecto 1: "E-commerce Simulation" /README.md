# 🧪 Plan de Pruebas y Testing Exploratorio

## 📋 Descripción

Desarrollé un **plan de pruebas** orientado a evaluar la funcionalidad y experiencia de la sección de registro (**Sign-Up**) de una aplicación web.

El proyecto incluyó la creación y ejecución de **casos de prueba**, la realización de **pruebas exploratorias manuales** y el **reporte de errores y oportunidades de mejora** detectadas durante el proceso.

## 🎯 Objetivo

Evaluar el funcionamiento de la sección de registro mediante diferentes escenarios de prueba, identificando posibles errores y aspectos susceptibles de mejora.

## 🔎 Actividades realizadas

- Definición y ejecución de casos de prueba.
- Realización de pruebas exploratorias manuales en la sección **Sign-Up**.
- Identificación y documentación de errores.
- Elaboración de reportes de bugs.
- Propuesta de mejoras para la aplicación web.

## 🛠️ Tipo de testing

- **Testing Manual**
- **Pruebas Exploratorias**
- **Pruebas Funcionales**

## 📂 Contenido

Este proyecto contiene la documentación y evidencias correspondientes a las pruebas realizadas, incluyendo los casos de prueba, errores encontrados y sugerencias de mejora.
