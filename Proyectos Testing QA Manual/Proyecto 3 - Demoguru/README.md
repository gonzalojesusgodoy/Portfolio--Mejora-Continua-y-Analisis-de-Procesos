#### Proyecto 2: *"Demoguru"*

**Descripción:** Realicé pruebas manuales en el sitio web de demostración "Demoguru", con el objetivo de verificar el correcto funcionamiento de sus principales funcionalidades. El proyecto estuvo enfocado en evaluar el comportamiento del sistema, identificar posibles defectos y comprobar que las funcionalidades respondieran de acuerdo con lo esperado.

- **Actividad:** Me enfoqué en la creación y ejecución de casos de prueba manuales sobre las principales funcionalidades de la plataforma, evaluando diferentes escenarios positivos y negativos para detectar errores y validar el correcto funcionamiento del sistema.
